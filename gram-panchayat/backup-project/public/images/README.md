# Logo Placeholder

Place your Gram Panchayat logo here as `logo.png`

**Recommended specifications:**
- Format: PNG with transparent background
- Size: 200x200 pixels (square)
- File name: logo.png

**Default fallback:**
The application currently uses an emoji icon (🏛️) as fallback if logo.png is not found.

**To add your logo:**
1. Save your logo file as `logo.png`
2. Place it in this directory: `public/images/logo.png`
3. Refresh the browser

**Free resources for government logos:**
- https://www.flaticon.com (search "government building")
- https://www.iconfinder.com (search "panchayat")
- You can also use Canva to create a simple logo
